# Наблюдаемость контекста и JEV — 21.10.2026

Согласовано владельцем: «Обзор → Загрузка ролей» показывает вклад энричеров и JEV; «Настройки → Оценщик JEV» показывает расход по сохранённому ключу. Старт разрешён 21.10.2026.

## Реализация
1. Сервер: журнал операций с task/step/role/run, стартом, завершением, временем, причиной пропуска/ошибки, входным/выходным количеством и списком источников. AsyncLocalStorage изолирует параллельные роли. Учёт токенов по непрозрачному отпечатку провайдера и ключа; сам ключ не выдаётся. Неизвестный usage не равен нулю. Никаких платных проб для статистики.
2. Python TaskContext: отдельные результаты KB/Mnemosyne/repository/dependencies/history, время поиска и фактически включённые в ограниченный prompt данные; мост сохраняет метаданные. Сбой журнала не ломает рабочий запуск.
3. JEV: все пять сценариев, вызовы, причины fallback, конкретный результат отбора/оценки; тест подключения тоже учитывается. API статистики только владельцу. Периоды 24 часа, 7 и 30 дней; в загрузке также 3 дня. Без подтверждённого тарифа/баланса показывается недоступность денежных данных, не выдуманный ноль. Локальный учёт обозначен как расход TaskFlow с датой старта.
4. iOS: секция под текущим графиком, сводка и последние операции с деталями и переходом к карточке. В настройках — расход текущего ключа по периодам/сценариям. Ошибки загрузки отдельны от пустой истории. Подсказки новой функции.
5. Сторож журнала: транзакционная проба записи/чтения/агрегации с rollback, уведомление в состоянии системы с ограничением частоты. Запись в docs/watchers.md.

## Проверка
До логики — падающие тесты. Сервер: mock-провайдер, независимые параллельные контексты, смена ключа, неизвестный usage, ошибка и timeout, отсутствие секретов в публичном ответе, права owner, периоды, сторож. Python: обрезка и источники. iOS: декодирование и состояния, целевой XCUITest в симуляторе и на iPhone. Не создавать живые задачи. Перед выкладкой проверить пустую очередь: активные роли не прерывать. Коммиты только своих файлов, без push.

## Серверная реализация
Миграция 163 создаёт журнал context_operations и дату старта. Owner-only GET /api/coordination/context-observability и GET /api/jev/usage. Локальные скользящие периоды: 24h/3d/week/month. Токены берутся только из usage; неизвестные расходы учитываются отдельно. Баланс и деньги недоступны: в официальном TypeSafe API опубликованы inference и models, отдельный billing endpoint не подтверждён. Статистика не включает другие приложения, использующие тот же ключ.

Привязка: queue worker передаёт task/job, запуск шага — task/subtask/role/attempt через AsyncLocalStorage. Явный context bridge и roleProjectContext сохраняют собственные идентификаторы; роли в ручных нестандартных путях могут иметь неполную привязку, она не угадывается по тексту карточки. Защищённый tfrole файл inProcessRun.ts не изменялся. Метаданные не содержат prompt, API-ключ, тело ошибки или содержимое памяти: только заголовки/счётчики.

Проверки на этом этапе: RED — отсутствующие наблюдаемость и Python context_observations. GREEN — 45 unit/API тестов (новые и JEV/TaskContext), 14 интеграционных тестов очереди/зависимостей/артефактов, tsc --noEmit, Python-тест обрезки и разделения источников. Существующий полный Python-набор запущен отдельно. Сторож записывает/читает пробную запись с rollback, без живых задач и вызовов модели.

## Дополнение: приёмка и реальный вклад
Целевой XCUITest ContextObservabilityUITests/testContextAndJevUsageReadOnly прошёл на iPhone Air iOS 27.0 Simulator и физическом iPhone Air iOS 27.0.1 (00008150-001545400144401C), без изменения живых задач и настроек JEV. xcresult и кадры — в docs/2026-10-21-context-jev-observability/ нативного репозитория. Приложение возвращено к обычному запуску.

На живом сервере начались штатные ходы critic_verifier; журнал уже показал: навыки 12→4, JEV-отбор памяти 15→14, окончательная передача памяти 283 кандидата→8 записей, библиотека 3→3. В TaskContext KB 4 найдено→3 полностью вошли; Мнемозина недоступна; сводка репозитория не вошла из-за лимита общего контекста. Это наблюдения, не исправления источников. Расход первого хода JEV: 9402 входных / 474 выходных токена (два запроса); последующие ходы увеличивают счётчик.

При финальной проверке дополнительно найдены и закрыты два слепых места: ошибка библиотеки проекта и ошибка чтения памяти теперь записываются как source_unavailable. Две регрессии упали до правки и прошли после: contextObservability 13/13 + JEV 27/27, tsc PASS. Сохранено прежнее поведение: модель продолжает без необязательного источника. Время чтения памяти теперь измеряется с начала поиска, а не после него.
