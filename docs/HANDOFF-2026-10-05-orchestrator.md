- Задача сдана → прочитать вердикт критика (`subtasks.result`) → проверить, что результат закоммичен в `roles/<task_id>` (роли часто не коммитят — закоммитить в их worktree) → `git merge --no-ff roles/<id>` в main → Linear Done с комментарием.

- Перед удалением задачи — проверить, что у неё нет идущего запуска (в т.ч. inproc — не виден в очереди); иначе сервер падает (А17).
