## Как работать (рецепт)

- Ключи: `TASKFLOW_AGENT_TOKEN` («Клод код», создаёт задачи), `TASKFLOW_ORCHESTRATOR_CLAUDE_TOKEN` (планы, утверждение, чаты, `run`). Только через `~/.claude/vault-run.py`, значения не печатать.
- Скрипты: `~/Проекты/New-Todoist/scripts/orchestrator/` — `tf_launch.py` (новая задача + план + утверждение), `tf_recreate.py`, `tf_review.py`, `tf_watch.py` (сторож: задачи, сообщения ролей, падение сервера, застревание; запускать фоном с env `T`=оркестратор, `A`=агент и списком id), `tasks-in-progress.txt`.
- Задача сдана → прочитать вердикт критика (`subtasks.result`) → проверить, что результат закоммичен в `roles/<task_id>` (роли часто не коммитят — закоммитить в их worktree) → `git merge --no-ff roles/<id>` в main → Linear Done с комментарием.
- Вливание кода **сервера** — только когда очередь пуста: `tsx watch` перезапускает сервер и рвёт работающие роли; при конфликте маркеры сразу убирать (сервер падает на них).
- Перед удалением задачи — проверить, что у неё нет идущего запуска (в т.ч. inproc — не виден в очереди); иначе сервер падает (А17).
- Сервер выполняет до 3 запусков параллельно (`ROLE_RUN_CONCURRENCY`).
