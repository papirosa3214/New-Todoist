## Что делает система дальше

Перенос в `main` выполняет очередь автослияния (временная копия → слияние → тесты → перенос → уборка).
Ручного слияния не делал, `main` не правил.

**Важно для переноса:** сдача шага с артефактом очередь автослияния не ставит — её ставит
`PATCH /api/subtasks/:id` с `done=true`, а проход обслуживания пропускает карточки, у которых
строка очереди уже есть. Строка карточки в `worktree_merge_queue` осталась в состоянии `merged`
от прохода 21.10 00:42 МСК, когда сливались первые коммиты. Поэтому два новых коммита
(`6a0e41ae`, `bf9cdca4`) сами в `main` не доедут: строку очереди карточки нужно вернуть
в `queued` — это делает сервер (Инженер .110), вручную в `main` вливать не нужно.
