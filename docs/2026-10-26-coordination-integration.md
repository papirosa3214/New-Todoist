# Доработка координации — 26.10.2026

## Серверный результат
Диагностические GET task/subtask/attempt теперь проверяют getTaskForRead: чужие/архивные задачи не раскрываются через обходной маршрут. В resolutions добавлены необязательные title/done/skipped/assignee_name/waiting_for. Завершённые, пропущенные и архивные шаги не предлагают действие; задача без подзадач получает task-level объяснение с subtask_id=null. Выбранный шаг и попытка отдают тот же читаемый контракт. Из links убраны несуществующие маршруты приёмки/финального ревью/снятия зависимости и несовместимая ручка retry: старые ссылки нельзя было вызывать как простую кнопку.

Resolver остаётся объясняющим механизмом. Новых маршрутов запуска и записей в рабочие задачи не добавлено. Перезапуск из клиента использует существующий POST /subtasks/:id/restart с ролью, причиной и прежними серверными правами/правилами admission.
