## 1. Сеть .110 — починено (главное этой сессии)

**Симптом:** с `.110` не открывались `youtube.com` и `api.tavily.com` (таймаут), при этом
обычный интернет и `google.com` работали; с мака YouTube открывался.

**Две причины:**
1. **MTU завышен** — интерфейс 1500, путь держит ~1488. Пакет 1472 не проходит, 1460 — да.
   Лечение: `mtu 1450`, закреплено в NetworkManager:
   `nmcli con mod "Проводное подключение 2" 802-3-ethernet.mtu 1450`.
2. **Провайдер блокирует YouTube/Tavily**, а свой VPN на `.110` (подписка `vpnctl`) YouTube не
   проводил **ни на одном сервере**. Рабочий выход нашёлся **на маке**: клиент **Happ** ходил через
   **Нидерланды, VLESS grpc+reality** (`nl-api.cdn-ozon.icu:2443`).

**Что сделано:**
- Выход с мака перенесён в два сервиса на `.110` (бэкапы конфигов рядом):
  - `~/.config/xray-claude/config.json` — outbound `fi` → NL (HTTP 10811 / SOCKS 10812);
  - `~/.config/xray-bots/config.json` — outbound `se1` → NL (SOCKS 10810, слушает `0.0.0.0`).
  - Применить: `systemctl --user restart xray-claude` / `xray-bots`.
- **Туннель sing-box** (`happ-vpn.service`) ходил «мёртвым» выходом через socks `10820`;
  переключён на рабочий socks `10812`: `/etc/happ-vpn/config.json`, outbound `xray-out`.
  Бэкап `.bak-before-10811`.
- **Маршрутизация**: в таблицу 100 добавлен LAN (`192.168.1.0/24 dev enp7s0`) и завернута
  подсеть n8n (`172.21.0.0/16`) — иначе её Telegram не доходил. Убран мой забытый тестовый
  маршрут (`from all to 142.251.153.4 lookup 100`).
  Закреплять в `/usr/local/sbin/happ-vpn-route.sh` (там уже есть правило Kaneo `10.0.4.0/24`).

**Проверено:** с `.110` `youtube.com` 200, `google.com` 200, `api.tavily.com` 200; туннель до
Telegram 302; бот релея **реально отправил сообщение** (message_id 1643).

**Как повторить, если выход умрёт:** вытащить активный сервер из Happ на маке —
`defaults read ~/Library/Group\ Containers/group.su.ffg.happ.lite/Library/Preferences/group.su.ffg.happ.lite.plist`
(ключ `connectedConfigJson`), перенести в xray-claude/xray-bots, перезапустить.

**Урок в базу знаний залит:** `2026-09-21-110-network-youtube-blocked-vpn-exit-from-mac`
(в RAGFlow, ищется `kb_get.py --find "youtube tavily с 110 ..."`).

## 4. TaskFlow — что сделано в этой сессии (запушено)

**iOS (`TaskFlowNativeBuild`, ветка `feature/reviewer-first-review`):**
- профиль агента: «Модель» — меню доступных моделей по провайдеру (не «весь интернет»); резервные
  модели удалены; «Инструкции» раскрываются полным текстом; точки-статусы убраны, статус словом;
  шапка (аватар/имя/назначение) возвращена; «Инструменты» — как раздел MCP по-русски;
  стиль приведён к эталону «Модели и голоса»; caps-заголовки выровнены.
- заметки: «Собрать постановку» (большой текст → родитель + дочерние через
  `POST /ai/structure-draft`); «Выгрузить в Markdown» — системный лист (был серый пустой);
  прогресс-плашка на время AI-операций; таймаут запроса (structure-draft 300с).
- карточка задачи: ярлычки действий агента (иконки + «N действий»); «Прикрепить файл» — меню
  «С iPhone» / «Из базы знаний»; удаление и замена вложений (длинное нажатие/свайп); шире типы
  файлов (код/скрипты); секция «Отчёты» (зеркало документов из доков проекта).

**Сервер (`New-Todoist`):**
- `GET /api/ai/prompts` отдаёт `defaults` (серверные промпты как placeholder) + scope `task_intake`;
- `POST /api/ai/structure-draft` — постановка из произвольного текста (локальная модель, дерево
  карточек, зеркало-заметка), `createDraftFromText` прикладывает исходник `.md` к родителю;
- `num_ctx` для постановки поднят до 16384 (было 8192 → обрезка промпта → одна убогая карточка);
- вложения: принимаем любые файлы (text/*, код, octet-stream);
- отчёты: `POST /api/tasks/:id/reports` (markdown → светлый HTML + PDF через headless Chrome,
  титул с «когда/кем/по какой задаче», зеркало-заметка в папке проекта), `GET /api/tasks/:id/reports`,
  `GET /api/reports/:id/:format`, таблица `task_reports`;
- MCP-инструменты исследователя: `taskflow_web_get` (страница → чистый markdown),
  `taskflow_ocr` (скан/PDF → текст, tesseract rus+eng), `taskflow_web_search` (Tavily→Brave),
  `taskflow_youtube` (субтитры; `player_client=web,mweb`); промпт роли дополнен конвейером
  «план → сбор → проверка → синтез → отчёт»; allowlist роли расширен (31 инструмент);
  прокси (`HTTPS_PROXY=http://127.0.0.1:10811`) прописан в профиль роли.

**Pi-плагин** `server/scripts/pi-extensions/taskflow-activity.ts` (действия инструментов в карточку)
+ установщик `server/scripts/install-pi-extensions.sh`.

- **Но** `POST /webhook/alert` отдаёт пустой ответ/таймаут, а прямой `POST http://127.0.0.1:8099/send`
  висит ~35с, хотя **тот же curl руками из контейнера проходит** (302). То есть дело уже не в сети —
  копать сам релей (`/relay.py`) и n8n (в логах цикл падений IMAP-воркфлоу «БГ — документы по почте»
  с ECONNRESET/EPIPE и реактивациями; n8n перезапускали — не помогло).
