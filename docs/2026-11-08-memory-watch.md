# Память TaskFlow как интеграция: кто обращается и окно поиска

Дата: 08.11.2026. Владелец: «добавь интеграцию TaskFlow именно Mnemosyne… хочу видеть
количество раз по конкретным агентам, кто туда обращается, и мне должен быть окно
ввода, чтобы я мог сам запрашивать информацию и смотреть, что там за барахло валяется».

## Что сделано

Память одна — Mnemosyne. Банки (`tf-team`, `tf-role-<роль>`) держат приватность:
роль видит свою и командную, владелец — всё.

Сервер (`~/Проекты/New-Todoist/server`):

- миграция `212_memory_access_log` — журнал обращений: кто спросил, о чём, сколько
  нашлось. Тела записи в журнале нет: копия памяти в журнале — лишняя утечка;
- `src/lib/memoryAccessLog.ts`:
  - `logMemoryAccess({roleKey, query, hits, kind})` — запись в журнал, падение
    журнала не ломает ответ роли;
  - `memoryAgentStats()` — по агенту: обращений всего, за неделю, когда последнее,
    сколько записей держит, сколько раз их читали (`memories.use_count`). Роли,
    которые ещё не спрашивали, тоже в списке — иначе «не видно» читается как
    «нет памяти»;
  - `memoryBanksInUse()` / `roleKeyOfBank()` — какие банки реально заполнены;
- `src/lib/memory.ts` — `recall` стал обёрткой над `recallInner`: журнал пишется в
  `finally`, поэтому упавший поиск тоже виден владельцу;
- `src/routes/memoryWatch.ts` (новый файл, чтобы не трогать `routes/memory.ts` —
  это экран «Память ролей», у него свой контракт):
  - `GET /api/memory/agents` → `{agents, banks}`;
  - `GET /api/memory/browse?q=&limit=` → `{items, banks}`; пустой запрос — свежее
    сверху из локальной таблицы, с запросом — поиск по банкам через
    `recallAcrossBanks` (ручной поиск владельца тоже пишется в журнал, `kind=owner`).

Клиент (`/Users/max/Проекты/TaskFlowNativeBuild`):

- `Sources/Core/Networking/APIClient+MemoryBanks.swift` — модели и два запроса;
- `Sources/Features/Settings/TaskflowMemoryScreen.swift` — «Кто обращается» (имя,
  «80 записей · 214 прочтений», «12 обращений»), строка банков и поле поиска в
  шапке (`searchable`), найденное — карточками с названием банка;
- «Интеграции» → «Подключения TaskFlow» → строка «Память TaskFlow»;
- подсказка `settings-taskflow-memory` на строке входа (правило «новая функция —
  новая подсказка»), тест `testTaskflowMemoryHintCompletes`.
