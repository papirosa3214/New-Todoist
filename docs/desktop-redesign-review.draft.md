# Десктопный веб TaskFlow — разбор концепций (черновик, 19.10.2026)

Источник: `~/.hermes/cache/scratch/taskflow-html/rabochiy-stol-taskflow.html` (фаворит) и
`~/Проекты/Html/client-graph-variants/*.html` (18 штук) на маке. Скриншоты сняты headless Chrome 1600×1000,
разбор — скилл `critique`.

## Главное наблюдение

«Рабочий стол» — это сам TaskFlow (навигация → разговор по задаче → исполнение командой).
18 вариантов — один экран «граф агентов вокруг Goose» в разных формах. Это не альтернативы
рабочему столу, а кандидаты в его разделы.

## Каркас: «Рабочий стол» — правки

| Сейчас                                                          | Как лучше                                                            | Почему                        |
| --------------------------------------------------------------- | -------------------------------------------------------------------- | ----------------------------- |
| Красный цвет означает и бренд, и выбранный проект, и «В работе» | Красный только бренду и тревогам, «в работе» — нейтральным или синим | Работа читается как ошибка    |
| Справа подряд схема команды, результаты, команда                | Вкладки «Ход / Результаты / Лог»                                     | Перегруз, низ уходит за экран |
| Команда показана дважды: в схеме и списком                      | Только схема, подробности по клику                                   | Повтор                        |
| Над чатом крошки, заголовок и строка мета                       | Без крошек, мета одной строкой                                       | Больше высоты чату            |

## Что взять из вариантов

- **split / packet** — журнал пакетов как вкладка «Лог» справа.
- **kanban** — переключатель «Лента / Доска» у проекта.
- **monitoring** — экран «Состояние системы» (метрики, расход, тревоги сторожей).
- **classic / tree** — экран «Агенты»: каталог + карточка агента.
- **atelier / control-room** — маленький граф связей внутри карточки агента.

## Не брать

orbit, voxel, chord, bubble, river, field — эффектно, но читаются хуже списка.
terminal, hybrid-dark — это тема оформления, а не компоновка.

## Итоговая карта

Слева: Входящие · Мои задачи · Проекты · Чаты · Документы · Агенты · Состояние системы · Архив.
В центре: задача-разговор; у проекта — Лента/Доска.
Справа: Ход · Результаты · Лог.
