# Закрытый чек-лист роли в чате — как сейчас и как откатить

26.10.2026, решение владельца.

## Как сейчас (коммит `2c100b23`)

- Пока чек-лист роли в чате идёт, действия считаются по текущему пункту (лимит 100 + 50).
- Роль закрыла чек-лист — **этот ход она доигрывает** с инструментами.
- На **следующее сообщение** владельца инструменты закрыты, пока роль не заведёт новый чек-лист.
  Всегда доступны: завести план (`taskflow_work_plan`), написать владельцу, задать вопрос с вариантами.
- Работа совсем без чек-листа не ограничивается — как и раньше.
- Чек-лист из одного-двух пунктов владельцу не показывается (коммит `642389d8`): роль ведёт его у себя, полоски нет.

Где в коде: `server/src/runtime/chatActionBudget.ts`, функция `reserveChatItemAction`, ветка «Закрытый план».
«Тот же ход» сервер узнаёт так: план заведён на то же сообщение владельца, на которое роль сейчас отвечает (`source_message_id`).

## Точка отката — «закрытый план = плана нет» (коммит `d1ddbf94`)

Если роль начнёт упираться («не могу прочитать», «план завершён») на мелочах — вернуть прежнее поведение:
после закрытого чек-листа роль работает без ограничений, как без плана.

Откат одной командой (в `~/Проекты/New-Todoist`):

```bash
git revert --no-edit 2c100b23 && cd server && npm run build && systemctl --user restart taskflow-server.service
```

Скрытие маленьких планов откатывается отдельно, если понадобится: `git revert --no-edit 642389d8`.
