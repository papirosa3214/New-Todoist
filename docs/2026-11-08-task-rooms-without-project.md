# Комната задачи без проектных чатов

Дата: 08.11.2026, Europe/Moscow. Владелец: «чатов в рамках проектов просто не
должно существовать». Основание — `docs/2026-11-08-role-slot-chat-branches-spec.md`
§1–3, §9, первый шаг реализации.

## Что было

- `chats` держала всё в одной таблице: комнаты (`room_kind` personal/dm/common/
  wake/handoff), **группа проекта** (`project_id`, `parent_chat_id IS NULL`) и
  **тема задачи** — дочерний чат группы проекта (`task_id` + `parent_chat_id`).
- `lib/projectTopics.ts:ensurePlanTopic()` без проекта возвращал `null`: у
  задачи вне проекта рабочей комнаты не появлялось вовсе. Инвентаризация живой
  базы 08.11.2026: 116 активных задач, комнат 21 (14 с проектом + 7 без),
  56 активных задач без проекта — 49 из них без комнаты.
- Проектных групп было 8. Переписка — только в одной: одно сообщение владельца
  «Есть кто?» (10.10.2026). Остальные семь пустые.

## Что стало

- Комната задачи — самостоятельная **групповая комната**: `room_kind='task'`,
  один на задачу (`UNIQUE(task_id) WHERE room_kind='task'`), без `project_id` и
  без `parent_chat_id`. Заводится независимо от проекта.
- В личной комнате каждой роли-участника та же комната видна **топиком**:
  таблица `chat_room_topics(personal_chat_id, room_chat_id, role_id)`. Это
  представление одной истории — ID чата и сообщения одни, копий нет.
- Проект — только папка владельца. Чата у проекта нет: `POST /api/projects/:id/chat`
  удалён, `DELETE FROM chats WHERE project_id = ?` при удалении проекта убран,
  триггер `project_topic_insert` снят. Восемь старых групп удалены миграцией.
- Право убирать: комнату задачи убирает любой её участник (как раньше тему
  задачи) — `lib/chatArchive.ts:isTaskRoom`.

## Миграция 202_task_rooms

1. Пересборка `chats`: в CHECK `room_kind` добавлено `'task'` (в SQLite
   CHECK-список через ALTER не меняется; признак подделывать под другой
   `room_kind` нельзя — так уже было с пересборкой в 053). Пересборка
   `noTransaction: true`, держит свою транзакцию, строки и индексы сохраняются,
   `PRAGMA foreign_key_check` до/после сравнивается.
2. Прежние темы задач → `room_kind='task'`, `parent_chat_id`/`project_id` NULL.
   Уникальность: `idx_task_room`. Сняты `idx_task_topic`, `idx_project_chat`,
   `idx_chat_topics`; добавлен `idx_chats_task`.
3. `chat_room_topics` заполнена по фактическим участникам: у каждой роли —
   строка в её личной комнате.
4. Ручная переписка, жившая внутри проектной группы (одна, 23 сообщения), не
   удалена: отвязана от проекта и стала обычным групповым чатом.
5. Проектные чаты удалены (вместе с их собственной перепиской — 1 сообщение).
   Переписка комнат задач к этому моменту уже отвязана, проверка это
   подтверждает: 59 комнат до и после.

Прогон миграции на копии живой базы (`/tmp/mig-test.db`, `.backup`): 59 комнат
задач, 0 проектных чатов, 0 чатов с родителем, 179 топиков, переписка
2478 → 2477 (удалено одно сообщение проектной группы), FK-нарушений 262 → 3.

## Код

- `lib/projectTopics.ts`: `ensurePlanTopic` → **`ensureTaskRoom`** (без проекта,
  участники — владельцы трекера, создатель/владелец проекта, роли утверждённого
  плана, оркестраторы; топики в личных комнатах). `setTaskTopicClosed` →
  `setTaskRoomClosed`, `taskTopicClosedAt` → `taskRoomClosedAt`,
  `isTaskTopicClosed` → `isTaskRoomClosed`. Добавлены `TASK_ROOM_SQL`,
  `isTaskRoom`, `taskRoomOf`, `roomsOfPersonalChat`. `rehomeEmptyTopic` удалён:
  переселять комнату между проектами больше не нужно.
- `lib/chatArchive.ts`: `isTaskTopic` → `isTaskRoom`; отбор кандидатов уборки —
  по `room_kind='task'`.
- `routes/chats.ts`: комната задачи в доступе `isMember` проверяется доступом к
  карточке, проект в этом не участвует; все проверки «это тема задачи» — по
  `room_kind`; `GET /api/chats/:id/topics` у личной комнаты отдаёт комнаты
  задач её роли; `PATCH /api/chats/:id` не перепривязывает комнату задачи
  (409), иначе уникальный индекс отвечал 500.
- `runtime/taskChatContext.ts`: `resolveTaskChat` находит/заводит комнату задачи
  через `ensureTaskRoom` (раньше строил тему в группе проекта).
- `runtime/stepTopicProgress.ts`, `runtime/branchPlan.ts`,
  `runtime/inProcessRun.ts`, `runtime/agentMessaging.ts` — тот же предикат.
- `routes/projects.ts` — удаление проекта больше не удаляет чаты.

## Что не входило

Дочерние сессии слотов, карточки назначений, изоляция личного контекста,
`@`-адресация слота, передача со сжатием, архив/удаление чатов в клиенте, iOS —
следующие шаги спецификации. Проект для задачи по-прежнему не обязателен, но и
не мешает.
