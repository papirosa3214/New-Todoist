# Things: общий инструмент и полный ответ голоса

19.10.2026. Голос и текст используют один taskflow из buildRoleToolCatalog.

- Реальный вызов через voice Unix socket → taskflow_things3 → gateway → Mac Host → Things прочитал проекты.
- Обнаружена обрезка envelope голоса на 12000 символах: JSON терял валидность. Добавлен регрессионный тест с ответом 15000 символов (RED), обрезка удалена (GREEN 5/5).
- Контракт операций берётся из одного things_tools_contract.json на Mac; сервер хранит синхронизированную копию для схемы/описания. Host читает canonical при каждом вызове.
- Добавлен things_ui: узкий AX backend только com.culturedcode.ThingsMac; inspect возвращает snapshot и номера элементов; действие требует тот же snapshot, иначе STALE_SNAPSHOT. Изменение всегда требует повторной проверки.
- URL write backend использует существующий локальный токен, не передаёт его роли, не печатает URL; успех только по x-success, при таймауте may_have_changed и запрет слепого повтора.
- UI-only функции требуют незаблокированного сеанса macOS. Это не доступ с Linux напрямую в Things Cloud.

Проверки и live результат дополняются после внедрения. Живой голосовой звонок не выполнялся.
