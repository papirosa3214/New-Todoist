# Jev: укрепление и два новых сценария — 24.10.2026

## Согласованное поведение
Jev помогает действующему механизму: замечания к отчёту получает критик, намерение сообщения получает отвечающая роль. Сам Jev не блокирует сдачу, не запускает работу, не меняет права и не создаёт карточки. Ошибка или недостаточная уверенность сохраняет текущий путь.

## Реализация
- Строгая проверка типов, конечности чисел и диапазона 0–1; неполное решение по делегированию не используется.
- Явно заданные навыки этапа обязательны и не сокращаются Jev.
- Общий дедлайн включает получение и чтение ответа; прекращает ожидание даже если fetch не обработал abort. Задержку заблокированного event loop таймер устранить не может.
- Версия из ответа записывается в существующий защищённый журнал; выбранный алиас автоматически не меняется.
- Отчёты: только перед запуском критика, оценка актуальных материалов задачи; узкие проверки связи с заданием, наличия доказательств и оговорок. Критик сам проверяет замечания по источникам.
- Намерения: вопрос, обсуждение, поручение, продолжение, остановка, смешанное/неясное. Передаётся исходный текст и небольшой предыдущий контекст. Оценка не является разрешением; явные команды и выбранный режим сильнее неё. Покрываются новый ход и сообщения в уже работающий чат.
- Два независимых выключателя через существующий API настроек и веб-экран. При первой выкладке включаются по поручению владельца. По умолчанию в новых установках выключены.
- Существующая наблюдаемость и её сторож покрывают новые сценарии.

## Проверка
В работе. До изменений логики — падающие тесты; сеть Jev в тестах подменяется, БД временная. Живые пользовательские сообщения не создаются ради проверки.
