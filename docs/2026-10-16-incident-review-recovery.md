# Восстановление автопроверки поломок — 16.10.2026

## Причина
Поломка Ollama сдана 12.10 в 20:39 МСК, до внедрения обязательного Критика 14.10.
Карточка уже имела agent_state=review. finishCompletedPlans исключал такие
карточки из восстановления, поэтому у неё не было узла Критика, задания review
или вердикта. Надпись ожидания не означала существование запуска.

## Исправление
При восстановлении сданных планов отдельно находятся активные неархивные
поломки на проверке с последним утверждённым планом, всеми сданными шагами,
без узла итоговой проверки, вердиктов и открытых предложений изменения плана.
Создание узла, задания и события incident_review_recovered атомарно.
Используются штатные ensurePlanFinalReviewer и queuePlanFinalReview.
Обычные задачи, незавершённые планы и уже проверенные результаты не меняются.
Повторный вызов не создаёт дубль.

## Проверка
- До исправления: регрессия не находит review job (0 вместо 1), 3 теста проходят.
- После: incidentReview и planReviewLifecycle — 9/9 PASS.
- npm run build — PASS, Node 22.23.1.
- Живое восстановление штатной функцией из собранного модуля: recovered=1.
- В живой БД задание running, итоговый шаг in_progress у critic_verifier.
- Перезапуск сервера для восстановления не требовался, идущие роли не прерывались.
- Живой итог: review job succeeded, итоговый шаг done, вердикт approved 16.10 в 16:47 МСК; карточка completed. Критик сообщил о проверках эмбеддингов, параллельных запросов, поиска и чата. Самостоятельно повторно эти запросы не запускались.
- Ограничение вердикта: восстановлена доступность после рестарта, внутренний дефект очереди Ollama не устранён; повтор возможен.

## Границы
Правки только цикла проверки поломок. Не отключали общие настройки,
не закрывали карточку вручную, не меняли результат исполнителя.
