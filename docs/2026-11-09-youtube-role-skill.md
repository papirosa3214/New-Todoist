# Навык YouTube для ролей

Дата: 09.11.2026.

Навык `youtube-research` создан в постоянной папке Исследователя:

`/home/maksim/taskflow/roles/researcher/skills/youtube-research/SKILL.md`

Рантайм намеренно подключает папку навыков Исследователя и Помощнику владельца
(`skillPathsFor('secretary')`), поэтому это один общий навык без расходящихся
копий. JEV видит в шапке явные триггеры: `youtube.com`, `youtu.be`, Shorts и
запросы на разбор/пересказ ролика.

Правило навыка: ссылка сама по себе означает работу с содержимым. Роль вызывает
`youtube` через предоставленный `research_server.py`, после чего отвечает по
полученному тексту. Сервер сам выбирает прямой API субтитров и резервные пути;
навык не даёт роли доступ к куки или браузеру.

Когда внешний JEV недоступен, локальный `bge-m3-embed` дополнительно сопоставляет
сообщение и описание `youtube-research`. Резерв включается только при явном
признаке YouTube (ссылка `youtu.be`/`youtube.com` либо просьба о видео YouTube)
и не отбирает остальные навыки.
