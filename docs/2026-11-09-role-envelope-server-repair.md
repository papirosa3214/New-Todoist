# Серверная починка конверта ответа роли

## Решение

JSON-конверт ответа — ответственность сервера, а не модели. Сервер извлекает доступное содержимое и строит канонический конверт v1 со всеми обязательными полями.

## Поведение

1. Неполный или типово ошибочный структурированный ответ с сохранённым смыслом: сервер нормализует поля и сразу доставляет результат владельцу.
2. Совсем неразбираемый ответ без извлекаемого текста: сервер не показывает владельцу JSON-ошибку, а один раз просит роль исправить ответ, передавая ей детали нарушения.
3. Если и повтор не даёт пригодного содержимого: владелец получает нейтральное сообщение о невозможности оформить ответ, без технических деталей контракта.
