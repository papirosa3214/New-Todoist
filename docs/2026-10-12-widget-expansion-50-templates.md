## Итог

В `roles/secretary/skills/widget-recipes/templates/` лежат 50 готовых
шаблонов (по одному файлу на рецепт) плюс 7 прежних. `validate_widget.py`
на собранном из 50 шаблонов файле выдаёт `проверено: 50, ок: 50, ошибок: 0`.

## Состав

- **50 новых файлов** в `templates/` с именами `NN_K_slug.md`
  (NN — тема, K — порядок внутри темы).
- **Распределение по типам:** metrics 10, progress 10, checklist 11,
  card 10, chart 7, weather 2.
- **Темы:** финансы, здоровье, обучение, путешествия, календарь, дом,
  привычки, покупки, погода по маршруту, отчёты по проектам, задачи
  TaskFlow, команда / агенты.
- Каждый файл содержит: тему, ID концепции, формулировку «когда применять»,
  источник данных, готовый блок ```widget, короткие правила.
- В `widget-recipes/SKILL.md` таблица рецептов расширена: 6 базовых +
  `interactive_chart` + 50 бытовых = 57 строк.

## Проверки

- `python3 roles/secretary/skills/widget-renderer/scripts/validate_widget.py /tmp/builder-work-50/all_50_widgets.txt`
  → `проверено: 50, ок: 50, ошибок: 0`, exit 0.
- Каждый из 50 файлов открывается, содержит ровно один блок ```widget,
  который парсится валидатором в `type ∈ {metrics, progress, checklist,
  card, chart, weather}` и проходит проверку обязательных полей.
- Прежние 7 файлов (task_stats, my_overdue, weather, release_progress,
  task_card, agent_activity, interactive_chart) не трогались.

## Ограничения

- Шаблоны в реальной папке `roles/secretary/...`, эта папка не в git —
  коммит здесь фиксирует только отчёт и список файлов, перенос в main
  (после ревью) сделает ответственный за интеграцию.
- Источники данных (банковская выписка, Apple Health, Google Calendar,
  Stepik, OZON, банк-цели) подключены как предполагаемые — часть из них
  в текущем секретаре не реализована, это будущая работа за рамками
  карточки.
- Концепция 9.1 «Погода по маршруту» описана одним блоком weather;
  в рецепте указано, что в одном ответе их нужно ставить подряд по
  числу точек маршрута.
- 50 JSON-примеров валидируются автономно, но визуального рендера
  каждого в клиенте TaskFlow на этой итерации не было — это часть
  приёмки критика.
