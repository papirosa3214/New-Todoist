# Серверная подготовка текста карточки — 07.11.2026

По поручению владельца iOS читает чат, заметки и описания карточек только из подготовленной сервером структуры; локальный запасной Markdown-разбор удаляется.

`hydrateTask` добавляет `title_document`, `description_document` (TipTap для редактора) и `description_blocks` (нативный просмотр, включая таблицы и виджеты). Строки `title`/`description` сохраняются без изменения. Формат хранения БД не меняется. Чат уже возвращает `blocks`, заметки — TipTap `content`; их API не изменён.

Проверка: `test/chatBlocks.test.ts --maxWorkers=4`: новые два теста RED (нет подготовленных полей) → GREEN; всего 13 тестов. Проверены разметка, таблицы, пустое описание и неизменность исходных строк.

Доставка: через существующий deploy-when-idle, после освобождения очереди и штатной резервной копии. Фактические SHA, health и проверка API — в итоговом отчёте владельцу.
