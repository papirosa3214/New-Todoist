# GitHub через существующий Composio MCP — 28.10.2026

Владелец выбрал стандартную авторизацию GitHub через Composio. Нового MCP и
передачи токена в песочницу нет. Подготовленный прототип launcher удалён до
коммита и на Mac не устанавливался.

Общий канон `server/scripts/role-system-prompt.md` объясняет discovery реальных
операций, публикацию ветки/файлов/коммитов, создание либо обновление PR, проверку
CI и автоcлияние. Указаны оба репозитория и отличие локального SHA от GitHub SHA.
Этот канон разворачивается сервером в SYSTEM.md каждой роли.

GitHub разрешается всем текущим ролям в существующей role_composio, остальные
разрешения сохраняются. Аккаунт подключает сам владелец существующей кнопкой:
Настройки → Интеграции → Composio → найти GitHub → Подключить аккаунт.
До его OAuth-подключения выполнять GitHub-действия через Composio нельзя.

Проверки: имена MCP сверены с composioRuntime.ts и composio_mcp.mjs; формат
публикации определяется реальными схемами discovery, названия tool_slug не
выдумываются. Учётная запись GitHub на момент начала настройки отсутствовала.
Проверка авторизованного действия зависит от завершения OAuth владельцем.
