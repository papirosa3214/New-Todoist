# Интеграция серверных обсуждений 252c400e — 26.10.2026

## Решение и границы

Прямое поручение владельца: проверить и перенести серверную часть обсуждений в main на .110. Из ветки roles/252c400e-aa8e-4cab-9993-0d7e85388e1e выборочно адаптированы 9d3f873b и e95f48ce. Полное слияние старой ветки отвергнуто: оно конфликтует с более новым durable checkpoint в main. Его логика и UUID fence сохранены.

Обсуждение использует отдельную сессию и аренду; разрешает чтение, не управляет рабочим этапом. Закрытие ждёт весь текущий ход, включая подготовку и сохранение. Таймаут оставляет closing без преждевременного handoff. Повторное закрытие сериализовано. Закрытые обсуждения не принимают новые сообщения через оба маршрута; писать может владелец.

Передача использует реального получателя, детерминированный ID и сохранение ID до побочного действия. Запись очереди не считается потреблением: accept требует delivered_at. Повтор failed steer разрешён. При старте реального сервера восстанавливаются ожидающие handoff; отдельного периодического восстановителя нет. Ошибки инструментов останавливают только сессию обсуждения, а не рабочую попытку. Используется актуальный native catalog.
