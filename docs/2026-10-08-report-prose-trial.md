# Проба исходного человеческого отчёта
08.10.2026. Владелец разрешил изменить исходный отчёт вместо добавления редактора Qwen, с возможностью отката при ухудшении работы команды.

## Применено
В AGENTS.md восьми включённых ролей добавлен помеченный пробный раздел. Финальный текст по задаче — обычный Markdown без внешнего ok/output/artifacts/error конверта. Отчёт сохраняет пять обязательных разделов. Структурные аргументы инструментов, payload, evidence, verdict и ключи зависимостей сохраняются. Чатовый/голосовой машинный контракт не меняется. Старые документы не переписываются.
Эффективный загрузчик текущего server/dist подтвердил новый раздел для 8/8 ролей. Модель для проверки не запускалась; реальная читаемость и влияние на работу команды ещё не подтверждены.

## Откат оформления
Сохранены восемь оригинальных файлов и manifest в /home/maksim/backups/taskflow/report-prose-trial-20261008-131535.
Команда: python3 /home/maksim/backups/taskflow/report-prose-trial-20261008-131535/rollback.py
Она удаляет только помеченный пробный раздел, сохраняя остальные инструкции, включая правила подтверждения сдачи и ID критика. Перезапуск не нужен; новые заходы загрузят прежний формат.

## Критик и ошибочный ID
Подготовлена программная нормализация: ID собственного шага текущей задачи преобразуется в ID этой карточки до запроса versions. Другая карточка или чужой шаг отклоняются. Это отдельное исправление исполнения, оно не откатывается вместе с пробным оформлением.

## Наблюдение
На следующих реальных отчётах проверить: понятен ли итог, не потеряны ли доказательства и дефекты, получает ли следующая роль полный структурный результат, проходит ли фактическая сдача. Ухудшение — основание откатить оформление без изменения статусов задач.
