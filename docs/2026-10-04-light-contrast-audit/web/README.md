# Светлая и тёмная темы веба — кадры для аудита контраста

Снимки экрана веба в обеих темах. Лежат рядом с iOS-кадрами из этого
же аудита (`docs/2026-10-04-light-contrast-audit/` в репозитории
`TaskFlowNativeBuild`) для прямого сравнения одной платформы с другой
на одних и тех же экранах.

Светлые кадры — критерий приёмки MAK-46, тёмные — добавлены 05.10.2026
в рамках MAK-51 (пилюли, приоритет, аватары), чтобы пилюля «Просрочено»,
шевроны приоритета и аватар исполнителя были видны рядом с iOS-эталоном
не только в светлой теме, но и в той, в которой приложение работает
по умолчанию.

## Вьюпорт

402×874, deviceScaleFactor=2. Браузер Chromium, headless, мобильный
профиль (touch, mobile=true). Запуск:

- `node scripts/screenshot-light-theme.mjs` — кладёт `taskflow-ui` в
  localStorage с `settings.theme="light"`, затем проходит три экрана.
- `node scripts/screenshot-dark-theme.mjs` — идёт без persist-стейта,
  App.tsx ставит дефолтную тёмную тему на `<html>`, затем проходит
  те же три экрана.

Оба требуют работающий dev-сервер `npm run dev` на :5180 и
`TASKFLOW_LAN_NO_AUTH=1` на backend :3001.

## Кадры

Светлая тема (эта папка):

- `today-light.png` — экран «Сегодня» (Понедельник, 5 окт.), секция
  «Ждут вас» с активной задачей и бейдж «на проверке» (синий акцент).
- `task-detail-light.png` — карточка задачи `ad4a56a9…` (MAK-57).
  Видны: проект «TaskFlow - NewTodoist» в синем акценте (#246da3),
  заголовок, описание с `## Работа`, действия в шапке.
- `projects-light.png` — список проектов с цветными аватарами.

Тёмная тема (папка `dark/`):

- `today-dark.png` — те же секции «Ждут вас» / «Просрочено» / «Сегодня»,
  пилюля «Просрочено» красная (red/15), шевроны приоритета 4/3/2/1
  цветом свотча (P1 red, P2 orange, P3 blue, P4 sub), аватары
  исполнителей 30px с инициалами.
- `task-detail-dark.png` — карточка задачи с флажком и словом
  «Приоритет» цветом приоритета (НЕ шевроны в свёрнутом виде — это
  правило с 18.08.2026) и аватаром исполнителя 32px.
- `projects-dark.png` — список проектов в тёмной палитре по умолчанию
  (sub #a6a6a6, dim #949494, red #e44332).

## Что НЕ менялось

`@theme` (тёмная) эти кадры не трогают, и `:root[data-theme="light"]`
не задевает тёмные токены. Скрипт тёмной съёмки идёт без persist-стейта
специально, чтобы App.tsx сам поставил дефолтную тему.

## Скрипты съёмки

`scripts/screenshot-light-theme.mjs` и `scripts/screenshot-dark-theme.mjs`
— отдельные Node-скрипты без test-runner. Перед загрузкой кладут
(или не кладут) `taskflow-ui` в localStorage, открывают корень,
RequireAuth делает LAN-логин (без пароля), затем переходят по `/today`,
`/task/<id>`, `/projects` и снимают PNG.

В скриптах подменены ТОЛЬКО ответы `/api/tasks/<id>/collaboration-plans`
и `/api/tasks/<id>/role-slots` на пустые — CollaborationPlanPanel
на живой задаче MAK-57 падает в ErrorBoundary из-за бага, не
относящегося к этой задаче (роли приходят в неожиданной форме).
Панель плана в шапку аудита цветов не вносит, а остальная карточка
(шапка, проект, описание, таббар, FAB) — на 100% живая, с настоящими
данными владельца.
