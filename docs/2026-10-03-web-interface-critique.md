# Веб TaskFlow: предварительный аудит и порядок улучшений

Дата: 03.10.2026. Проект: /home/maksim/Проекты/New-Todoist.
Цель владельца: сделать веб-интерфейс приемлемым и приятным; ограничить расход ресурсов.

## Достоверность

Две независимые проверки выполнены GPT-6-Luna с low reasoning. Навигация по исходникам — через существующий Graft, без перестроения графа. Главные production-маршруты: /overview и /today; /timeline и /inbox-timeline — экспериментальные экраны и не подменяют основной интерфейс.

Визуальная приёмка заблокирована: свежие вкладки встроенного браузера отвергли https://192.168.1.110:5180 с ERR_CERT_AUTHORITY_INVALID. Предупреждение сертификата должен подтвердить владелец. UI не просмотрен, оценки по десяти эвристикам не выставлены. Ошибка доступа — ограничение проверки, а не P0-дефект приложения.

Детектор Impeccable запущен один раз на копиях Layout.tsx и OverviewScreen.tsx: JSON [], 0 находок. Это не подтверждает качество UX или отсутствие проблем доступности. Временные файлы удалены; overlay не запускался, ничего не инъецировалось, временных серверов нет. Context launcher ошибочно прочитал текущий нативный cwd, поэтому его рекомендации о продукте не применялись к вебу; веб-контекст прочитан напрямую из DESIGN.md и Graft. Slug/archive механизма Impeccable не использован; этот документ — отдельный проектный артефакт. Ignore list не проверен; это предварительный source-only аудит, не полный critique run.

## После доступа в браузер

Один совместный проход desktop/mobile: Обзор, Сегодня, открытая карточка задачи. Проверить первый очевидный шаг, плотность, читаемость, приоритеты действий, клавиатурный фокус, нижнюю панель и перекрытия. Затем один пакет правок и один подтверждающий проход, без многократного полирования. Эвристики: статус системы, язык пользователя, контроль, последовательность, предотвращение ошибок, узнавание, эффективность, минимализм, восстановление, помощь — пока все не проверены визуально.

Пользовательские сценарии: владельцу быстро понять, что требует внимания; клавиатурой создать/открыть задачу; на телефоне прочитать сводку и перейти к работе. Когнитивную нагрузку и эмоциональное восприятие до визуального просмотра не оценивали.
