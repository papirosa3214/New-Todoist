# Понятные ошибки и шаблоны taskflow — 20.10.2026

## Результат
Общая инструкция taskflow содержит точные JSON-примеры discover, describe, invoke со сводкой. describe обычной операции и requests.status/reconcile возвращает invokeTemplate, templateFields (пути, типы, обязательность, описания, примеры), templateInstructions.
Шаблон включает обязательные поля, version=1 и верхний request_id для записи. Необязательные поля представлены в templateFields, но не подмешиваются в основной вызов. Строки <…> и примерные числа нужно заменить реальными данными. При anyOf/oneOf показан первый вариант и явно указано сверять другие варианты с inputSchema. Шаблон не означает разрешение на действие.

Ошибки INVALID_ARGUMENTS объясняют путь, фактический тип/значение и ожидаемый тип/перечисление вместо сравнения одинаковых имён ключей. Лишний arguments.arguments: точные переносы и исправленный вызов. Массив в {item:[...]}: ожидается массив, получен объект, перенос items.item → items. Вложенные ошибки указывают arguments.items[0].id/state. Законный вложенный arguments у host сохраняется.
Чувствительные поля маскируются; показ значения ограничен. Исправленный пример сохраняет содержимое без обрезки; при размере более 8000 символов возвращаются инструкции переноса вместо изменённого/обрезанного примера.
request_id: контекстная инструкция добавить ключ без повторного поиска каталога. Специальные подсказки адаптеров сохранены.
