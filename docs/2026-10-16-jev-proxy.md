# TypeSafe JEV через Xray Claude — 16.10.2026

## Причина
Прямой GET /v1/models возвращал 451: Typesafe is not available in your region.
Тот же ключ через существующий HTTP-прокси Xray Claude возвращает 200.

## Изменение
Только запросы JEV к hostname api.typesafe.ai используют выделенный
undici.ProxyAgent на локальном HTTP-входе Xray Claude.
И проверка подключения, и оценка используют общий call(). Глобальный
dispatcher, VPN, DNS и конфигурация Xray не менялись.
Ключ, адрес, модель jev-latest и выключатели сценариев сохранены.
undici добавлен прямой зависимостью (уже был установлен транзитивно).

## Проверка
Новая регрессия до правки: 1 FAIL / 26 PASS; после правки 27 PASS.
npm run build PASS. Перед перезапуском runtime-status active_runs=0,
в durable очереди нет running/queued/retry_wait.
Проверена принадлежность порта 3001 systemd taskflow-server.
После штатного перезапуска POST /api/jev/test: HTTP200,
ok=true, модели jev-latest/jev-preview, 321 мс.
Это проверка сохранённого подключения, не результат реального сценария роли.

## Версии
Документация https://docs.typesafe.ai/models на 16.10:
jev-latest → jev-1.13.0; jev-preview → jev-1.14.0.
Предварительная 1.14 опубликована 14.10, заявлено улучшение многоязычности.
Алиасы могут менять версию; выбранная модель автоматически не менялась.
