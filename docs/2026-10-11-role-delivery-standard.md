[Открыть документ](https://192.168.1.110:5180/notes/0f503d69-bf61-4482-b285-ec388d7d1e3a).

Все роли должны сразу сохранять человекочитаемый отчёт в документации задачи, передавать report_markdown при сдаче и давать короткий итог со ссылкой. Отчёт содержит результат, изменения, проверки, ограничения и материалы. Назначенный в карточке ответственный собирает итоговый документ, итоговый коммит и интеграцию.

Зафиксированы границы карточек, серверные worktree, единственный каталог нативного проекта, явная передача своих файлов/участков, проверка подготовленного diff и сохранение чужих изменений. В общем грязном каталоге запрещены git add ., git add -A, git commit -a. Смешанные изменения одного файла разделяются до коммита. Коммит, main, выкладка и живая проверка описываются отдельно.

Полный регламент хранится в библиотеке; системный промпт содержит короткое обязательное правило, прямую ссылку и команду чтения документа. Подключение выполнено через общий roleHomeInstruction: персональный системный текст и настройки роли не скрывают стандарт. Противоречие «полный отчёт / только три строки» устранено: три строки относятся к короткой сводке в чате.
