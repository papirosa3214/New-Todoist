# Исследователь: переход на JSON v1

**Статус:** подготовлен локальный fallback-промпт; не внедрён в живой сервис.

## Изменение

`server/scripts/role-prompts/researcher.md` теперь требует от финального сообщения один объект `schema_version: 1` с восемью обязательными ключами и закрытым набором типов блоков. Инструкция сохраняет план → сбор → проверку → локальный синтез → `taskflow_report`. Развёрнутый markdown-отчёт сдаётся инструментом и не заменяется JSON-ответом в чате.

## Источник инструкции

Read-only запрос к рабочей БД `.110` 17.10.2026 показал пустой `roles.prompt` для `researcher`; текущий источник — fallback `scripts/role-prompts/researcher.md`. База не изменялась.

## Границы и следующий шаг

Это изменение только файла fallback в изолированной серверной ветке. Оно не меняет промпт в базе, не запускает модель и не переводит другие роли. До применения в живой системе нужны проверка генерации ответа на тестовом ходе и подтверждение, что финальный конверт проходит серверную валидацию, а отчёт всё ещё создаётся через `taskflow_report`.
