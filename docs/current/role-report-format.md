# Оформление отчётов

В общей инструкции report_markdown добавлены: заголовки второго уровня, выборочное жирное выделение итога и дефектов, списки с дефисами для тезисов, нумерация для последовательности. Таблицы только для сравнения, 2–3 коротких столбца для телефона. Шрифты и размеры остаются у приложения, без HTML/CSS в отчёте.

В обычном документе iOS Mermaid пока отображается как код. По умолчанию схемы — короткие последовательности со стрелками и вложенные списки. Mermaid допустим в специально запрошенном HTML/PDF, где предусмотрен рендеринг. Не требовать схемы и таблицы для каждого отчёта.

Проверено 8 октября 2026 на iPhone Air simulator iOS27 через временный XCUITest: обычный документ с жирным текстом, списками, таблицей, стрелками и контрольным Mermaid. Таблица содержит доступные ячейки Сохранено/Возвращено; Mermaid виден как flowchart LR. Тест прошёл, кадры сняты. Продуктовый iOS код не менялся, на физический телефон установка не требовалась.

Образец в документации проекта: b000ada0-5e57-49cb-96c2-34522482bd7e. Это образец форматирования, не повторная приёмка архива.
