# Понятные отчёты ролей

8 октября 2026. По просьбе Максима общая инструкция отчётов дополнена конкретным стилем: итог и пользовательское поведение в начале, короткие объяснения по-русски, технические имена и ссылки только в разделе Материалы. JSON остаётся структурным входом следующей роли.

Сохранены пять существующих разделов и серверный контракт. Для критика требуется понятный вывод и описание дефекта: действие пользователя, фактическое поведение, ожидаемое поведение, ответственный этап. result/summary/findings также должны быть понятными; технические статусы и ключи остаются в аргументах инструмента.

Инструкция включена в системный промпт каждого запуска роли, в том числе проверки задачи без отдельного слота. Это влияет на новые запуски; сохранённые отчёты не переписываются. Проверка структурного формата не оценивает литературное качество; требуется наблюдение за следующими реальными отчётами.

## Проверка и решение

Контрольный прогон обычной модели ролей на фактах архива: дополнительный редактор вернул идентичный текст. Он не исправил неточное число тестов и расширение браузерной проверки до дерева. Правила дополнены сохранением точных чисел, границ доказательств и запретом придумывать вердикт или обязательные действия владельца. Отдельный редактор не установлен. Сначала наблюдаем отчёты новых запусков с общей инструкцией. Старые документы не изменяются.

Серверные проверки контракта отчёта: 17 прошли. Тест инструмента критика обновлён: сдача через review, generic done отсутствует.
