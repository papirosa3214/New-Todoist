# Диктовка → постановка → подготовка

MAK-112, 9 октября 2026.

«Структурировать с AI» редактирует свободный текст названия и описания: краткое название, работа, результат, критерии приёмки и границы. Уместные шаги возвращаются в `subtasks`; для точечной правки допустим пустой список. Срок и приоритет заполняются только при явном указании. Если существенных данных не хватает, конкретный вопрос сохраняется в описании.

Раньше `/api/ai/structure-task` вызывал генератор командного плана и требовал `preparation`, который нативная форма затем не использовала. Отсюда ошибка «Отсутствует контракт подготовки задачи». Теперь отдельный редактор возвращает существующий контракт нативной формы. Следующее действие «Подготовка» получает оформленное описание и строит роли/зависимости.

Неверный JSON модели повторяется один раз. Сбой провайдера не маскируется под формат. При окончательной ошибке форма сохраняет исходный текст. Структурирование не сохраняет карточки и не запускает роли.

Проверки: 17 серверных тестов (редактор + существующий контракт подготовки), TypeScript; 2 нативных теста TaskStructureTests на iPhone Air. Реальная MiniMax: диктовка о высоте и прокрутке стрима → оформленный черновик с четырьмя разделами и четырьмя шагами → успешная подготовка с одним builder, без вопроса и без лишнего дробления. HTTP-контракт проверен через Fastify inject на изолированной тестовой базе; реальный HTTP после выкладки ещё не проверен.

Ответственный за интеграцию: Codex. Выкладка и проверка HTTP выполняются после разрешения перезапуска при двух сохранённых запусках в очереди либо после её освобождения.
