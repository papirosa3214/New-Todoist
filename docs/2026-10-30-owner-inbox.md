# Входящие обращения владельцу — 30.10.2026

GET /api/attention дополнен tickets. Старые groups остаются совместимыми.
Новая проекция только для владельца; агентам возвращается tickets=[].
Источники: открытые вопросы чатов с участием владельца, активные уточнения,
актуальные needs_input шаги и текущие blocked-причины с явным ожиданием владельца,
последний черновик плана, proposed-операции утверждённого плана.
Архивные/закрытые задачи и архивные проекты исключены. Никакие действия не выполняются GET-запросом.

Устойчивая идентичность: question:<id>, clarification:<task>, decision:<task>,
step:<id>, plan:<id>, plan-op:<id>. Независимые вопросы одного task_id не схлопываются.
Операция proposed остаётся видимой после смены версии плана: реальный decidePlanProposal
применяет её к текущему состоянию и проверяет возможность операции при принятии.
Устаревший план и уже решённая операция в проекцию не входят.

Дата обращения: вопрос/план/операция — created_at источника; уточнение — актуальная
needs_clarification preparation job или событие поля; блок — blocked_at/событие блокировки.
Legacy без собственного времени использует created_at задачи, а не updated_at/heartbeat.

Проверки: RED до реализации — 5/5 новых тестов падали без tickets.
GREEN — 9 новых + 5 существующих attention тестов; TypeScript --noEmit прошёл.
Дополнительный RED/GREEN — owner discretion и неизменный возраст ожидания.
Независимое read-only ревью выявило и исправило фильтр версии, схлопывание шагов и время.

Миграций БД нет. Запись не создаёт новую очередь разрешений.
Неформальное ожидание только в старом комментарии не становится настоящим разрешением;
требуется структурированный вопрос или текущая причина ожидания.
Клиент отвечает через существующий API chat questions; согласования открываются в задаче.

Выкладка: только PR/CI и штатный idle deploy, без принудительного перезапуска ролей.
Перед передачей в CI проверена очередь: живых attempts=0; создана SQLite backup
server/backups/pre-inbox-tickets-20261030-142137.db.
Откат: revert серверного коммита; прежний iOS продолжит читать groups, новый явно
сообщит об отсутствии поддержки tickets. Никаких изменений данных при откате нет.
