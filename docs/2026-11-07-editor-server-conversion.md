# Серверное преобразование ввода редактора — 07.11.2026

Поручение владельца: вынести оставшийся Markdown-разбор из редакторов iOS на сервер.

Используется существующий POST `/api/notes/markdown-to-doc`: чистое преобразование без создания заметок и записи в БД. В нативном клиенте добавлен вызов этого API для сырого ввода/диктовки и текста AI. Ввод в локальные блоки и черновики остаётся на телефоне; интерпретация Markdown выполняется сервером. Для уже сохранённых шагов `withSubtaskState` добавляет `title_document`, чтобы редактор не разбирал `title` самостоятельно.

Целевые проверки: `test/taskBatch.test.ts --maxWorkers=4` — 7 PASS. Новая проверка title_document прошла RED → GREEN. Дополнительно проверено, что markdown-to-doc отдаёт marks и таблицу и не создаёт записей в user_notes. Живой endpoint и штатная доставка проверяются после публикации.
