# Ручная доставка через PR — 04.11.2026

GitHub Actions CI и автослияние отключены в обоих репозиториях TaskFlow. Новый порядок: ветка → исключительно точечные локальные проверки изменённой логики и файлов → push → настоящий PR → агент сам выполняет merge PR и проверяет статус merged. Открытый PR не является доставкой; владелец не нажимает Merge.

Полные и глобальные тестовые прогоны запрещены. Для сервера — только явные файлы тестов с maxWorkers=4. Общий typecheck или сборка не заменяют точечную проверку. Штатная сборка при выкладке отдельно от тестов. Прежний запрет ролям самовольно запускать тесты сохранён: новое правило ограничивает объём разрешённых проверок, а не расширяет права.

Обновлены INDEX.md (симлинки AGENTS.md/CLAUDE.md), PROJECT-START, общий канон ролей и текст интеграционной инструкции agentState.ts. Из канона разворачиваются SYSTEM.md существующих ролей; личные AGENTS.md ролей не перезаписываются. Инструкции GitHub не должны ссылаться на обязательный CI или ждать job автослияния. Восстановление старых записей внутренней очереди TaskFlow — отдельная процедура, её реализация не менялась.

Проверка: только diff, поиск противоречий и синтаксис изменённого TypeScript-файла. Тесты, глобальный typecheck и симулятор не запускались. Доставка: PR с ручным слиянием; обновление канона ролей без ожидания GitHub CI.
