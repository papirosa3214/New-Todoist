# Привязка телефона по QR одной командой с сервера

08.11.2026, `LOCK-PAIR-QR-CLI-20261108`.

## Зачем

Домашний вход без пароля (`TASKFLOW_LAN_NO_AUTH`) выключен по требованию
владельца: любой процесс на `.110` получал права владельца одним `curl`.
После выключения код привязки в HTTP выдаёт только уже вошедший владелец —
а если токен устройства на телефоне пропал (переустановка приложения,
выход, ответ 401 и очистка связки ключей), войти нечем: `/auth/lan` отвечает
404, приложение показывает экран входа с паролем.

Команда на сервере закрывает именно этот случай. Она работает с базой
напрямую, под пользователем сервера, и требует физического доступа к
машине — в сети она ничего не открывает и прав не расширяет.

## Как выписать код

```bash
ssh maksim
cd ~/Проекты/New-Todoist/server
npx tsx scripts/pairing-code.ts        # ASCII-QR в терминале
npx tsx scripts/pairing-code.ts --no-qr  # только код и ссылка
```

Печатает владельца, одноразовый код (128 бит, 32 hex), ссылку
`taskflow://pair?v=1&code=…&host=…`, срок жизни и ASCII-QR.

- Код живёт **5 минут**, одноразовый, в базе лежит только sha256.
- Новый код гасит прежний неиспользованный: действующий QR всегда один.
- Адрес для поля `host` берётся из `TASKFLOW_PAIR_HOST`, по умолчанию
  `192.168.1.110:3001`. Дома это поле не влияет: приложение работает по
  своему встроенному адресу; оно нужно внешнему доступу через ретранслятор.
- `qrencode` на `.110` есть. Без него команда печатает код и ссылку —
  их можно ввести на телефоне вручную.
