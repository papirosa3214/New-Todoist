# Гант: статус работы является источником загрузки

12 октября 2026. По поручению владельца.

## Дефект

MAK-57 завершена 7 октября, критик одобрил, шаги done=1. Три записи запусков от 5 октября без ended_at рисовались как работа до сегодняшнего дня. В аудите БД: 202 незакрытых запуска у 65 completed-карточек. Живой API до изменения: 230 интервалов, active_now=0, open_slots=8, MAK-57=3.

## Изменение

Закрытые и архивные карточки исключены из всех слоёв Ганта. Завершённые интервалы на ещё открытых карточках тоже исключены: экран показывает текущую загрузку, а не старые заходы. Текущая работа определяется agent_state=in_progress и done=0 на открытой карточке. Незакрытая запись запуска сама по себе не делает работу активной; для времени и роли берётся только текущая запись. Назначенный работающий агент виден и без записи запуска. Сданный шаг и переход агента в review убирают текущую полосу. Ожидание review/blocked без исполнителя больше не выдаётся за текущую загрузку.

Старые attempts не удаляются и не исправляются выдуманными датами. Это внутренний формат совместимости API, а не самостоятельный источник занятости. API-поля сохранены, поэтому веб и iOS получают исправленную выборку без смены контракта.

## Проверки

14/14 серверных регрессий, TypeScript сборка. Completed с in_progress и пустым ended_at; done-шаг с пустым ended_at; state-only агент; переход в review без изменения attempts; нормальная историческая роль и настоящий активный запуск; архив. roleLoadWatcher пробует реальную выборку на временных строках и откатывает транзакцию, при сбое создаёт одну тревогу в сутки в «Серверных уведомлениях». Зарегистрирован в docs/watchers.md, при старте и каждые 15 минут.

## Публикация

Сборка в отдельный каталог /tmp/taskflow-role-load-state-dist. В работающий dist переносятся только index.js, routes/coordination.js и lib/roleLoadWatcher.js; чужие незавершённые runtime-правки не публикуются. Перед перезапуском проверяется отсутствие queued/running/retry_wait. Результат живой проверки дополняется после публикации.
