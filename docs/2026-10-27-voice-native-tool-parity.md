# Единые инструменты помощника: голос и чат
Дата: 27.10.2026.

## Причина
Чат уже использовал отдельные инструменты с JSON Schema и taskflow_tools. Голос продолжал публиковать общий taskflow с discover/describe/invoke и пять собственных коротких инструментов. При ошибке загрузки общего каталога голос запускался только с пятью базовыми инструментами.

## Изменение
- Голос собирает инструменты через тот же buildRoleToolCatalog и installNativeToolCore: ядро и taskflow_tools.
- Подключены те же адаптеры секретаря: Things, Composio и MCP. Ресурсы адаптеров живут до конца звонка и закрываются при завершении.
- taskflow_tools возвращает активные схемы; Python-воркер обновляет Agent.update_tools до возврата результата загрузчика. Подключённые инструменты сохраняются между запросами звонка.
- Отдельные инструменты вызываются с собственными аргументами через общий native execute: права, режим чата, проверка схемы и учёт действий сохраняются.
- Старые пять методов больше не объявлены инструментами модели. Общий taskflow не публикуется и не исполняется голосом.
- При ошибке/пустом каталоге урезанный звонок не запускается.
- Исходный чат, запись реплик и вложений сохранены. Инструкция голоса описывает текущий нативный механизм.
- Для ограничений Gemini поля произвольного JSON передаются строкой и восстанавливаются до проверки исходной схемы. Структурированные объекты/массивы остаются структурированными.
- Ключи запроса включают сессию звонка и идентификатор вызова.
