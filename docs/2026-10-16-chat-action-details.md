# Подробности шагов единого инструмента
Причина: общий обработчик LiveTurn сохранял tool=taskflow и искал подробности в верхнем args, хотя operation и arguments вложены в оболочку.
Исправление: invoke разворачивается в фактическое имя и аргументы операции перед формированием LiveItem. Сохраняется исходный toolCallId — ответ завершает тот же шаг. discover/describe имеют отдельные понятные подписи. Старый mcp тоже разворачивается.
Общий LiveTurn используется и чатом, и задачей. Имена read/write/edit/bash, путь SKILL.md, команда, запрос поиска снова доходят до существующего классификатора клиента и подробностей.
Отказ gateway ok=false помечается ошибкой, а ответ running/pending не выдаётся за успешное выполнение.
Старые сохранённые шаги без имени/аргументов операции задним числом не восстанавливаются из догадок.
Проверка: короткая имитация событий с реальными LiveTurn.snapshot/finish, без запросов к моделям; сборка TypeScript.
