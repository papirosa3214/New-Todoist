# Рутинами управляет помощник владельца — 26.10.2026

## Возможности

Десять нативных инструментов secretary: taskflow_routines, taskflow_routine_read, taskflow_routine_create, taskflow_routine_update, taskflow_routine_pause, taskflow_routine_resume, taskflow_routine_run_now, taskflow_routine_delete, taskflow_routine_runs, taskflow_routine_preview.

Список и чтение находятся в начальном ядре; остальные доступны через штатный taskflow_tools. У каждой операции точная JSON Schema. Изменение принимает только изменяемые поля, необязательные настройки можно явно снять null. Операции используют существующий API через asRole(secretary) — без подмены на владельца. Плановый режим разрешает чтение/историю/предпросмотр, изменения остаются только в режиме работы. Универсальная оболочка сохраняет аудит, идемпотентность и обработку ошибок.

Удаление рутины разрешено прямым поручением владельца на все манипуляции. Два узких барьера настроены согласованно: roleToolScope разрешает инструменты рутин только secretary, auth разрешает ей DELETE /api/schedules/:id. Другие DELETE и права других ролей не расширялись. Уже созданные задачи при удалении рутины остаются.
