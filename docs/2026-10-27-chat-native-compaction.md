## Изменение
В чатах удаляется принудительный compactSessionSafely при каждом восстановлении сохранённой сессии.
Настройки компакции не переопределяются: SDK использует собственные значения по умолчанию и фактический contextWindow модели.
Кнопка «Сжать контекст» вызывает session.compact() ровно один раз, со штатным структурированным промптом SDK.
Ошибка компакции возвращается вызывающему коду; локальная выжимка с отрезанием истории вместо результата не создаётся.
Обычные вызовы и результаты инструментов остаются частью текущего агентного диалога. Штатная компакция сохраняет свежий хвост, заменяет старую часть смысловой выжимкой и не режет пары вызов–результат.
Полные журналы сессий остаются журналами, не удаляются. Существующие прежние выжимки не переписываются.
Изменение ограничено чатами; отдельный цикл исполнения карточек не изменяется.
