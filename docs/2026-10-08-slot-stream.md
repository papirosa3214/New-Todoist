# Поток исполнителя в графе
08.10.2026.

LiveTurn умеет отдельный publish sink без регистрации/вещания в чатах. inProcessRun передаёт все runtime events в этот обработчик. tasks:live адресован владельцу/ответственному задачи; GET /tasks/:id/live использует существующую проверку доступа к activity.

Снимки изолированы task_id/subtask_id/run_id. Позднее завершение заменённого захода не затирает новый. Завершённый снимок хранится до 30 минут, действует ограничение числа завершённых снимков. При рестарте память очищается.

Проверки: tsc build; 22 теста (19 чатов и 3 потока). iOS build + 4 unit + 1 UI для восстановления привязки действий в графе.
Не проверено на физическом iPhone и новом живом заходе. Внешние исполнители с одним POST activity не передают текстовые дельты.
Статус: подготовлено, не включено в live. Перезапуск согласуется с владельцем, чтобы не прервать текущую работу.
