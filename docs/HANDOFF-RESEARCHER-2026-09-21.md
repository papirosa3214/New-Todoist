## Что осталось

Инструменты и промпт роли **готовы** (проверены по отдельности). Осталась серверная часть —
владелец просил «зафиксировать конвейер на сервере», сейчас порядок живёт только в промпте.

1. **Серверный конвейер исследования** (оркестратор по образцу машинной постановки,
   `ownerDraft.ts`): на задачу-исследование сервер сам гоняет
   **план → сбор (web_search / web_get / ocr / youtube / docs / kb) → валидацию локальной
   моделью → синтез → отчёт**. Шаги и повторы — в коде, а не в промпте; лимит итераций, стоп
   по «достаточно», статусы в ленту задачи; итог — `taskflow_report`.
2. **Флаг «нужно глубокое исследование» на задаче** — чтобы процесс не запускался на рабочих
   пустяках. Ставит владелец при создании либо Секретарь при постановке. Нужно решить:
   отдельное поле задачи (галочка в карточке, видна в списке) или пункт меню «…» карточки.
3. **Разделение моделей**: сбор и валидация — **основной** моделью (под которой идёт researcher),
   синтез — **локальной** (`qwen3.6-27b` на Ollama). Сейчас не закреплено.
4. **Лимит источников**: начать с **5–10** на прогон, дальше по качеству.
5. **E2E-прогон живого агента** с новыми инструментами не делали — тестировали инструменты
   по отдельности, не полный заход исследователя.

Готовые инструменты роли (31 в allowlist): `taskflow_web_get`, `taskflow_web_search`
(Tavily→Brave), `taskflow_ocr`, `taskflow_youtube` (`player_client=web,mweb`), `taskflow_report`.
