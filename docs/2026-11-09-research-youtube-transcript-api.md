# YouTube исследователя: прямой API субтитров

Дата: 09.11.2026.

## Причина

Путь через `yt-dlp` зависит от выдачи форматов плеера YouTube, JavaScript-решателя
и иногда от браузерной сессии. При их сбое даже у ролика с доступными субтитрами
инструмент переходил к скачиванию аудио и Whisper либо возвращал ошибку.

В проекте `/Users/max/Проекты/Youtube rus` уже был проверенный экстрактор на
`youtube-transcript-api`: он получает текстовую дорожку напрямую.

## Изменение

`server/scripts/mcp_server.py`, инструмент `youtube`, теперь идёт в таком порядке:

1. `youtube-transcript-api` получает субтитры по ID ролика напрямую;
2. при отсутствии дорожки или отказе API остаётся прежний резерв: `yt-dlp` с
   временной сессией из Secret Broker;
3. если субтитры этим путём недоступны, остаётся резервное локальное распознавание
   аудио Whisper.

Ответ сохраняет контракт и явно отдаёт `source: "youtube-transcript-api"` на
новом основном пути. Сессия из broker не раскрывается и не нужна для штатного
случая с доступными субтитрами.

## Зависимость

На .110 установлен `youtube-transcript-api 1.2.5` в пользовательское окружение
Python, под которым запускается инструмент. Перезапуск приложения и iOS-сборка
для этой серверной правки не требуются.
