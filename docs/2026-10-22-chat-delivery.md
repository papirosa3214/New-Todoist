# Доставка уточнений роли: 22.10.2026

## Изменено

- Обычное уточнение в том же чате больше не создаёт координационную карточку от имени владельца.
- Вопрос коллеги в той же комнате не создаёт внешнее обращение; межкомнатная связь сохраняется.
- Для рабочего запуска сохраняется карточка с task_id/subtask_id. Постановка в SDK показывает ожидание безопасной границы; delivered появляется по событию user message. Обрабатывается как steering, так и входящий текст при запуске слота.
- Успешный общий запуск не является доказательством отдельного ответа. answered требует сохранённого связанного ответа от нужной роли. Межкомнатное обязательство без ответа остаётся pending для восстановления.
- Внутренние Pi-сессии чата и задач выполняют инструменты последовательно и проверяют входящие перед следующим инструментом. Уже запущенное действие завершается. Ещё не начатые действия при уточнении получают явный результат об отложенном выполнении; затем модель пересматривает план с новым вводом. Существующий hook доступа сохраняется.
- Сообщение владельца больше не запрашивает замену рабочего запуска: слот продолжается через steering, без конкурирующего исполнителя.

## Ограничения

Граница между инструментами реализована для внутреннего Pi. Внешний CLI получает ввод через stdin и подтверждается по result; столь же раннюю реакцию его протоколом эта правка не обещает. cliAgentSession regression tests проходят.

Последовательное выполнение инструментов внутри одного ответа — сознательная цена точной границы; независимые роли не сериализуются этой правкой. Длинная уже начатая команда не прерывается.

Живые поручения и сообщения для проверки не создавались. Отдельный управляемый deploy/restart не запускался; возможный автоматический reload сервиса не считается приёмкой. Владелец ещё не проверял сценарий в приложении. По UI ничего не изменялось.
