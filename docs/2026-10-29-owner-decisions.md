## Субагенты: модель работы

- [x] **Субагент одноразовый.** Набирает контекст → сжимает в **выжимку** →
  отдаёт вызывающей роли → исчезает. Первичные источники перебирает он, а
  не вызывающая роль. Промпт и описание инструмента это проговаривают.
- [x] **Комната новая на каждый вызов** (вариант «а», не переиспользование по
  паре «сессия + роль»).
- [x] **Комната закрывается сама**, когда выжимка ушла в главную сессию;
  статус — `open` / `finished` / `failed`.
- [x] **Комнаты не показываются в списке сессий** — живут в боковой панели
  сессии, по ролям, со статусом. `GET /api/chats` их не отдаёт,
  `GET /api/chats/:id/subagent-rooms` — отдаёт.
- [x] **Кнопку «открыть комнату» в карточке НЕ делаем** — владелец отклонил
  28.10.2026: комната и так достигается из панели роли.
- [x] **Кнопка «Остановить обращение» на карточке субагента работает** —
  маршрут `/api/chats/:id/coordination/:messageId/stop` гасит ход роли
  напрямую (`cancelChatRunsFor`).
