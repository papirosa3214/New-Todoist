# Один системный текст Помощника — 04.11.2026

## Решение владельца

Только текстовый Pi-чат Помощника использует выбранный файл Qwen целиком. Текущая переданная владельцем редакция — 6829 символов, SHA256 d7d0025e9db47da0a1396ba896da71fe8b6a4d70adba5a0f7f11e48d34100953. Исходный результат первого прогона Qwen был 6456; установлен именно текущий приложенный файл, без правок агента.

Единственный источник: server/scripts/secretary-chat-system.md. Общий SYSTEM.md, AGENTS.md, ROLE.md, серверные дополнения режима/инструментов/плана и каталог навыков в системный текст этой ветки не добавляются. Другие роли, карточное исполнение и голосовая инструкция остаются на прежних источниках. Голосовой код не изменялся.

## Как обеспечивается точное совпадение

Загрузчик текстового чата Помощника не подмешивает контекстные файлы, навыки и append-секции. На границе SDK transformContext все системные сообщения (в том числе сохранённые/инкрементальные) заменяются одним сообщением с точным содержимым выбранного файла; текущие toolsAdded/toolsRemoved сворачиваются с сохранением схем активных инструментов. Права и ограничения инструментов остаются в коде, даже если текст модели пытается их расширить.

В пользовательский промпт Помощника не добавляются chat.wrapper/chat.followup, прежние карточные ограничения, фразы о лимите 100 слов и политики памяти. Вместо них — участники, история, текущая реплика, время/режим/идентификаторы и факты памяти/проекта. Классификатор JEV намерения не вызывается для этой текстовой ветки. Сами пользовательские сообщения и данные памяти сохраняются.

При доставке очищается только привязка старой Pi-сессии Помощника в chat_sessions (pi_session_id); chat_messages и файлы старых сессий не удаляются. Следующий ход получает историю чата через новый чистый сборщик, без старых серверных user-обёрток. Голосовая история берётся из chat_messages и не сбрасывается.
