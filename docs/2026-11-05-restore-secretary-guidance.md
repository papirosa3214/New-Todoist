# Возврат точечных подсказок Помощнику — 05.11.2026

По прямому требованию владельца возвращены memory/thrash-подсказки при вызовах инструментов. Они включаются в момент события tool_execution_start, только если соответствующий guard вернул непустой текст, и отправляются через session.steer. Постоянный системный файл (6829 символов) и отсутствие старых постоянных добавок сохранены. Подсказки об ошибках параметров инструментов и проверка прав ранее не отключались и не менялись в этой работе.

Ошибка предыдущей работы: замену постоянного системного текста необоснованно распространили на точечную обратную связь во время инструментального цикла. Это расширяло поручение владельца. Возврат касается только этого отключения.

Проверки исключительно точечные: secretarySinglePrompt.test.ts — RED 1 падает/4 проходят до исправления, GREEN 5/5 после. Первые и повторные запросы установленного SDK по-прежнему получают единственный выбранный системный текст; runtime guidance разрешён Помощнику. Глобальные тесты/typecheck, симулятор и реальные модельные запросы не запускались.
