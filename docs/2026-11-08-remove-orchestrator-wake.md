# Удаление пробуждений оркестратора и Заминок — 08.11.2026

## Границы
Владелец отменил механизм автопробуждения оркестратора и служебных чатов «Заминки». Уточнение владельца: контроль зависаний и уведомления во «Входящие» должны сохраниться.

## Изменения
Удалён orchestratorWake.ts и все его вызовы при блокировке/повторе шага, возврате проверяющим, согласовании плана, зависании и цикле ошибочных вызовов. Новые служебные чаты, сообщения и задания оркестратору больше не создаются. Правила Apple-уведомлений и описание инструмента очищены от обещаний канала Заминок.

Запросы на изменение плана в профиле orchestrated направляются существующим notifyPlanApprovalRequest владельцу: раньше этот профиль вместо уведомления владельцу создавал Заминки. Обычные блоки, сторож, лимиты автоперезапуска, остановка ошибочного цикла, события и postOwnerNotification сохранены. Старая история не удаляется; активные комнаты Заминок архивируются при доставке после резервной копии. Общий канал пробуждения внешних агентов/webhook не относится к этому механизму и не менялся.

## Проверки
41 проверка в пяти конкретных файлах: stalledStepWatcher (13), planOwnerApproval/orchestratedPlan (10), errorLoopStop (6), ownerInbox (12). Новые проверки RED → GREEN: согласование приходит владельцу, нет комнат/сообщений/очереди оркестратора; авто-блок сохраняет одно уведомление, занятый слот не останавливает сторож. Существующие проверки лимитов перезапуска, снимка брошенного шага, блокировки цикла и Входящих проходят.

Исправлена изоляция теста сторожа: TASKFLOW_RUNS_DIR указывает на временный корень, граница запуска роли заменена тестовой попыткой без реальной модели. Иначе свежая активность настоящего SDK маскировала искусственно состаренный журнал. Старые тесты прямого wake API удалены вместе с API и заменены проверками отсутствия запуска. В planOwnerApproval запрос тестового уведомления ограничен своей карточкой; проверка литерала инструкций оркестратора актуализирована к уже действующей фразе «В main вливает система», без изменения самих инструкций.

## Доставка
Точечные тесты PASS, diff PASS. Публикация main, штатная выкладка при пустой очереди, резервная копия, health и проверка Входящих/архивации выполняются перед завершением. iOS не меняется, установка не требуется.
