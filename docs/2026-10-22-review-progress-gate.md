# Повтор проверки только после сохранённого результата

22.10.2026. Продолжение исправления 34c53602 по прямому требованию владельца: если первый запуск ничего не сделал и не оставил результата, повтор не нужен.

## Поведение

Сервер делает снимок существующих результатов перед проверкой. Сравнивается содержимое документов задачи, результатов шагов критика и сданных артефактов. Используются существующие форматы; новый обязательный файл или контракт не вводится.

Если вердикт не сохранён и нового результата нет — карточка и узел блокируются сразу после первого захода. Повтор до контекста/JEV/модели запрещён. Отдельная проверка допуска повторного задания защищает после рестарта и при новом job.

Если есть новый сохранённый частичный результат, повтор допустим; общий потолок трёх заходов без вердикта сохраняется. Успехом проверки остаётся сохранённый вердикт.

Heartbeat, чтение инструментами, комментарии, старая выдача, повторная запись идентичного текста и изменение документа другой ролью не являются новым результатом критика. Снимок содержит хеши содержимого, а не копии документов; хранится в task_events review_run_started. На старых событиях без снимка отсутствие доказательства прогресса запрещает автоматический повтор.
