# Ручной запуск владельца — 28.10.2026

## Причина
Ограничитель автоматических повторов Критика применялся к ручной кнопке владельца.
Запуск шага не передавал признак ручной команды в durable queue. Другие роли
блокировались состоянием карточки/шага, закрытой попыткой и зависимостями.

## Поведение
Только аутентифицированный владелец при явном POST /tasks/:id/run или
POST /subtasks/:id/run может восстановить и запустить выбранную роль:
- прервать её живой ход и дождаться завершения до новой сессии;
- завершить зависшую попытку, отменить старые задания очереди;
- восстановить карточку из архива/завершения, снять блокировку;
- открыть завершённый/пропущенный шаг, разрешить его запуск без предшественников;
- повторить Критика без нового сохранённого результата и сверх автоматического бюджета.

Результаты прежних попыток и история событий сохраняются. Ручная команда записывается
в task_events как owner_manual_run. Признак manual_start сохраняется в очереди
для итогового Критика; ручное разрешение даёт одну попытку, max_attempts=1.
Автопродолжения и смена модели не наследуют разрешение обходить review-бюджет.
Автоматические вызовы с actorId владельца без явного manualStart обхода не получают.
Роли и оркестратор остаются на прежних проверках. Отключённая Система не включается.
