# Проверка срока карточки «Проверка срока 1792708606» (Аналитик, 23.10.2026)

## Что проверяли

Срок карточки — 24 октября без времени (приоритет 3, часа нет). Число в названии
1792708606 — метка момента времени Unix: 2026-10-22 22:36:46 UTC = 23.10.2026
01:36:46 МСК, на 15 секунд раньше создания карточки проверки срока (22:37:01 UTC).
Сроком эта метка не является.

## Числа

| Величина | Значение |
|---|---|
| Сегодня по Москве (Europe/Moscow) | 2026-10-23 |
| Дней до срока 2026-10-24 | 1 («завтра») |
| Подпись срока | «Завтра, 24 окт.» |
| Граница просрочки | 00:00 2026-10-25 МСК |
| Серверная эскалация: просрочка в 00:00 24.10 / в 00:00 25.10 | 0 ч / 24 ч |
| Шаг эскалации для приоритета 3 | 24 ч, срабатывает 00:00 25.10, уведомление в 08:00 (окно тишины 22:00–08:00) |

Проверено на четырёх часовых поясах устройства (Москва, Токио, Нью-Йорк,
Калининград): «сегодня» везде 2026-10-23, сдвига дня нет. Правила веба
(«просрочено» = дата срока раньше сегодняшней) и сервера совпадают.

## Находка (передана в отчёте шага)

Серверная эскалация считает просрочку от полуночи дня срока и не смотрит на час
(`start_time`). Для приоритетов 1 и 2 (шаги 1 ч и 4 ч) уведомление «Просрочено»
приходит ночью дня срока, раньше фактического часа задачи.

## Как воспроизвести

```
npx tsx workspace/analyst-srok/srok-check.ts
npx tsx workspace/analyst-srok/part.ts
```

Считаются чистые функции трекера: `src/lib/date.ts` (клиент) и
`server/src/lib/escalationEvaluator.ts` (сервер). База данных не читается.
