## Что НЕ сделано: main не сдвинут

Причина конкретная и проверенная: ролевой запуск идёт под пользователем
`tfrole`, а рабочая копия `/home/maksim/Проекты/New-Todoist` принадлежит
`maksim`.

```
$ touch /home/maksim/Проекты/New-Todoist/server/src/.__wtest
touch: невозможно выполнить touch …: Отказано в доступе
```

Каталог `.git` роли доступен (в нём есть ACL `user:tfrole:rwx`), поэтому
указатель `refs/heads/main` технически можно сдвинуть из моего запуска. Я этого
не сделал и не буду: живое дерево main осталось бы на старом содержимом, его
индекс разошёлся бы с HEAD, а сторож выкладки
`server/scripts/deploy-when-idle.py` работает именно с рабочим деревом
(проверяет `git branch --show-current` и `git rev-parse HEAD`, требует чистоты
`server/`). Получилась бы видимость переноса без переноса и без выкладки —
ровно тот случай, который в карточке 7efcc173 уже признан неверным.

главной копии, после чего перенос выполнит роль.
