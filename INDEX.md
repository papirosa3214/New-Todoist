## Нативный клиент: код здесь, сборка на Маке

Xcode есть только на Маке, поэтому сборка идёт так:

```bash
cd ~/Проекты/New-Todoist/native
./scripts/sync-build.sh sync     # залить исходники на Мак
./scripts/sync-build.sh sim      # + собрать под симулятор
./scripts/sync-build.sh device   # + подписать и поставить на iPhone
```

`~/Проекты/TaskFlowNativeBuild` **на Маке — зеркало rsync, а не копия кода.**
Правки, сделанные там, затираются следующим `sync`. Писать код только на .110.

Подписанная сборка на устройство требует разблокированного login keychain Мака
(иначе `errSecInternalComponent`): `/tmp/tf-devbuild.sh` на Маке принимает
пароль в stdin, ключ — `MAC_LOGIN_KEYCHAIN_PASSWORD` в vault на .110.
