## Важно для проверок: доска отвечает только по HTTPS

Обычный HTTP на порт 5180 **не отвечает**: соединение принимается и сразу закрывается без данных
(`curl` — «Empty reply from server», код 000; пустая отдача и в python, и в `nc`).
На том же порту успешно проходит TLS-рукопожатие с самоподписанным сертификатом
`CN=example.org` (SAN: localhost, 127.0.0.1, ::1) — на порту стоит локальный TLS-перехват,
и обычный HTTP туда не доходит.

Практический вывод: **доску TaskFlow проверять так**
`curl -sk https://192.168.1.110:5180/` (200 — жива).
Проверка по `http://` выглядит как падение доски и легко даёт ложную тревогу.
Боевой API на 3001, наоборот, отвечает только по HTTP (HTTPS на 3001 не проходит).
