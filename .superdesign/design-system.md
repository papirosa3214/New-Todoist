# TaskFlow — Design System

Источник истины: `DESIGN.md` (закреплён владельцем) + токены `src/index.css` (`@theme`, Tailwind v4).
Компактная выжимка токенов — в `.superdesign/init/theme.md`.

## 0. Что это за продукт

TaskFlow — пространство совместной работы человека и команды ИИ-агентов. Человек ставит
задачу, агенты выполняют её по ролям и слотам, человек принимает или возвращает работу.

Три правила, из которых выведено всё остальное:

1. **Один язык на всё приложение.** Одно и то же действие называется и выглядит одинаково везде.
2. **Красный — не украшение.** Это цвет активного состояния и тревоги. Обычное действие красным не красится.
3. **Ничего лишнего на экране.** Неактивный декор, дубли одного входа, индикаторы «тут что-то выбрано» — убираются.

Главный критерий — **предсказуемость**.

## 1. Цвета (тёмная тема — по умолчанию)

```
--color-bg          #171717    фон приложения
--color-card        #242424    поверхность карточки
--color-card2       #2b2b2b    вторая поверхность: контролы, плашки, выпадающие меню
--color-stroke      rgba(255,255,255,0.09)   разделители и рамки
--color-text        #ffffff    основной текст
--color-sub         #a6a6a6    вторичный текст, подписи
--color-dim         #949494    третичный текст, плейсхолдеры, неактивные пункты
```

**Единственный акцент:**
```
--color-red         #e44332    активная вкладка, выбранный пункт, первичная кнопка,
                                «сегодня» в календаре, просрочка, удаление
--color-red-solid   #d63a28    заливка ПОД БЕЛЫЙ текст (4.67:1, WCAG AA)
```

**Прикладные состояния** (никогда не как «второй акцент интерфейса»):
```
--color-teal     #35b8a3    в работе
--color-blue     #4a9fd8    на проверке, ссылки-действия
--color-purple   #a78bfa    сдано (в графе плана)
--color-green    #15937e    успех, принято, чекбокс, флаг готовности
--color-orange   #ff9a14    заблокировано, предупреждения
--color-coral    #ff6b6b    ошибки, «агент пропал», деструктивные действия
--color-pink     #ff7a8a
--color-yellow   #f7d038
```

Светлая тема переопределяет те же токены в `:root[data-theme="light"]`:
`bg #f4f4f5 · card #ffffff · card2 #ececee · text #171717 · sub #424242 · dim #4e4e4e · red #c53426`.
`--color-red-solid` в обеих темах одинаковый, чтобы primary-кнопка не «прыгала».

## 2. Шрифт

Одна системная гарнитура, никаких декоративных:

```
-apple-system, BlinkMacSystemFont, "SF Pro Text", "Avenir Next", "Segoe UI", Roboto, Arial, sans-serif
```

Шкала из десяти ступеней — классы `.tf-*`, размер/вес/трекинг задаются вместе:

| Ступень | Размер | Вес | Трекинг | Где |
| --- | --- | --- | --- | --- |
| `.tf-title-large` | 28px | 700 | −0.84px | заголовок корневого экрана |
| `.tf-task-title` | 20px | 600 | −0.40px | заголовок карточки задачи |
| `.tf-title` | 17px | 600 | −0.20px | заголовок вторичного экрана/шторки |
| `.tf-input` | 16px | 400 | −0.10px | **только** input/textarea |
| `.tf-body` | 15px | 400 | −0.03px | основной текст |
| `.tf-row` | 14px | 400 | 0 | строка списка, пункт меню |
| `.tf-action` | 13px | 400 | +0.10px | вторичное действие, подпись |
| `.tf-meta` | 12px | 500 | +0.14px | метаданные, статусы, счётчики |
| `.tf-caption` | 11px | 500 | +0.20px | мелкая подпись |
| `.tf-micro` | 10px | 500 | +0.25px | совсем мелкое |

Принцип: **крупнее заголовок — теснее трекинг, мельче текст — свободнее.**

## 4. Глубина и тени

**Глубина передаётся фоном, а не тенями:** `bg → card → card2`. Тени остаются только за
плавающими элементами: веер навигации, выпадающее меню, перетаскиваемая карточка.

```
--shadow-pop       0 10px 30px rgba(0,0,0,0.35)    поповер (единый для всего)
--shadow-dropdown  0 6px 16px  rgba(0,0,0,0.45)    выпадающий список
--shadow-fab       0 6px 16px  rgba(228,67,50,0.45)
--shadow-sticky    0 10px 16px -12px rgba(0,0,0,0.55)
```

## 5. Движение

```
--dur-instant     80ms    тоггл, микро-взаимодействие
--dur-fast        150ms   hover, цветовой кроссфейд
--dur-base        200ms   базовое движение интерфейса
--dur-slow        350ms   открытие шторки, смена вкладки
--dur-deliberate  500ms   разворот/сворачивание, drag
```

Движение подчёркивает смену состояния и остаётся спокойным при долгой работе.

## 6. Навигация

- **Десктоп:** `SideNav` — колонка `w-60`, пункты `h-12`, gap `gap-1`, `px-3`, `rounded-xl`,
  иконка 22px. Активный пункт: `text-red`. Неактивный: `text-dim`, hover `text-sub`.
  Бейдж счётчика — `tf-caption`, круглый, `bg-red text-white`.
- **Мобильный:** нижняя панель навигации, тап-зоны ≥44.
- Разделы верхнего уровня: Проекты · Сегодня · Предстоящее · Обзор · Дневник (+ Архив отдельным разделом).

## 7. Состояния — не только цветом

Каждое состояние несёт **подпись + пиктограмму + форму индикатора**, не один цвет:

| Состояние | Цвет | Подпись в продукте | Форма |
| --- | --- | --- | --- |
| ждёт зависимость | `--color-sub` | «Ждёт» | рамка сплошная, без заливки |
| готов к старту | `--color-blue` | «Готов к старту» | точечный индикатор |
| в работе | `--color-orange`/teal | «В работе» | пульсирующая точка |
| сдано | `--color-purple` | «Сдано» | сплошной маркер |
| принято | `--color-green` | «Принято» | галочка |
| на доработку | `--color-red` | «На доработку» | диагональная стрелка назад |
| заблокирован | `--color-orange` | «Заблокирован» | замок |
| пропущен | `--color-dim` | «Пропущен» | зачёркнутый круг |

## 8. Правила, которые нельзя нарушать

1. Только токены, никаких hex-литералов в стилях.
2. Красным красится только активное состояние и тревога.
3. Тап-зона ≥44×44, даже если иконка 18px.
4. Горизонтальный отступ экрана 16px, шапка и контент на одной вертикали.
5. Один красный акцент; прикладные цвета — только для состояний.
6. Никаких декоративных градиентов, свечений и паразитного декора.
