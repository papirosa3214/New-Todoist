# Группы проекта и темы задач — этап 2

03.10.2026. Реализовано локально на Mac. На .110 не развёрнуто; приложение владельца не установлено.

## Поведение

В списке чатов меню «+» → «Группа проекта» открывает выбор проекта. Повторный выбор возвращает ту же группу. Внутри есть общее обсуждение и отдельные темы задач. «Добавить тему задачи» предлагает карточки этого проекта, включая дочерние. Повторный выбор карточки возвращает существующую тему. Из темы работает существующая ссылка на задачу.

Темы не показываются отдельными строками общего списка чатов; непрочитанные темы входят в счётчик группы и видны внутри неё. Личные и обычные групповые чаты сохраняют прежний контракт.

## Хранение и API

Миграция 088_project_chat_topics добавляет chats.project_id и chats.parent_chat_id. Корневая запись — группа/общее обсуждение; дочерние записи — темы. Поэтому история, вложения, отметка прочтения, онлайн-ходы и сессии остаются существующими механизмами, изолированными по chat_id. Отдельная таблица сообщений тем не нужна.

- POST /api/projects/:projectId/chat — найти или создать группу, вернуть {chat}.
- POST /api/tasks/:taskId/topic — найти или создать тему и при необходимости группу, вернуть {chat}.
- GET /api/chats/:id/topics — темы, доступные участнику, вернуть {chats}.
- Существующие /api/chats/:id/messages, /read, /live и другие маршруты работают для общего обсуждения и каждой темы.

Уникальные partial indexes обеспечивают одну группу на проект и одну тему на задачу. Транзакция включает создание и членство инициатора. Триггер INSERT запрещает тему без задачи или с несовпадающими проектами группы и задачи. Старый PATCH не позволяет перепривязать проектную тему.

## Доступ

Группу создаёт пользователь, имеющий право работать с проектом. Создание темы требует доступа к задаче и проекту. Членство темы не заменяет доступ к карточке: при чтении, отправке, подборе отвечающих ролей и рассылке нового сообщения проверяется актуальный доступ. При переносе задачи в другой проект старую тему нельзя открыть как действующую; повторное создание отвечает 409. Автоматический перенос истории между проектами пока не реализован.

Создание темы добавляет инициатора. Автоматическое заполнение состава по графу и связь с рабочим запуском — следующий этап; здесь не имитируется автоматическое участие всех агентов.

## Ограничения и следующий шаг

Это инфраструктура тем и ручная навигация. Автоматическое создание при импорте Linear, подготовка плана, согласование, добавление участников из графа и доставка сообщения выполняющему слот агенту ещё не подключены. Следующий этап — инструменты и контекст темы в рабочих запусках с проверкой фактической доставки, без дублирующего выполнения.

Перед использованием требуется миграция/выкладка сервера и сборка/установка iOS. Решение о выкладке этой версии отдельно не принималось.
