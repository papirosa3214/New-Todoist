# Итог работы в чате TaskFlow

Владелец одобрил такой отчёт 23.10.2026. Это общий навык всех ролей чата.
Обязательное правило находится в общем каноне `role-chat-report.md` и
подаётся каждый новый ход, независимо от первого сообщения разговора.

Отвечай обычным JSON-конвертом контракта роли. Итог работы — один блок:

```json
{
  "type": "report",
  "report_kind": "final",
  "sections": {
    "result": [{"type": "text", "text": "Что изменилось для владельца"}],
    "work": [{"type": "list", "items": ["Что сделано"]}],
    "checks": [{"label": "Проверка пользовательского сценария", "status": "not_run"}],
    "limitations": [{"type": "text", "text": "Живая проверка ещё не проводилась"}],
    "materials": []
  }
}
```

- Пять секций обязательны. `result`, `work`, `limitations` — массивы
  блоков `text|heading|list|table|status`.
- `checks` — массив `{label,status}`; статусы:
  `passed|failed|blocked|skipped|not_run`. Факт запуска сборки не доказывает
  выполнение сценария владельца. Не объявляй непроверенное проверенным.
- `materials` — до восьми `{kind,title,ref}`, kind:
  `url|document|file|change|artifact|log`.
- Для заметки бери фактический `material.ref` из `taskflow_doc_write`
  или существующего документа. На телефоне работает `note://<uuid>`.
  Старые id с префиксами `report_...` и `review_...` клиент может не
  открыть: сохрани доступный документ с обычным UUID и используй его ref.
- Не копируй произвольный id из примера и не заменяй ссылку путём .110.
  У внешнего материала сохраняй настоящую http(s)-ссылку.
- Отдельные card-виджеты, голый список ссылок и несколько сообщений
  «Открыть в TaskFlow» не заменяют секцию материалов этого отчёта.
- Если материала нет, массив остаётся пустым; не создавай фиктивный документ.
- Обычный вопрос и промежуточные пояснения не требуют report. Итог не
  повторяется после каждого инструмента. Карточный report_markdown и
  subtask_done сохраняют свой порядок.

Сервер объединяет подготовленные через taskflow_chat_share_material ссылки
с материалами итогового отчёта по ref. В активном ходе инструмент готовит
материал к итоговому ответу, не рассылая отдельные карточки. Поэтому не нужно
отчитываться о каждой ссылке отдельно; достаточно одного итогового report.
