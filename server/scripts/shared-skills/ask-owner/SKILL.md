# Вопрос владельцу

Когда спрашивать — до реализации, если:
- от выбора зависит способ реализации;
- критерий приёмки неясен или читается двояко;
- действие необратимо, выходит за рамки задачи, требует перезапуска сервиса.

Когда не спрашивать: ответ есть в памяти (`taskflow_memory` · recall), документах (`taskflow_knowledge`) или коде.

Как: `taskflow_ask_user_question`, один вопрос — одна строка, 2–4 варианта с коротким пояснением, рекомендуемый первым с пометкой «(рекомендую)». В карточке вопрос уходит в чат задачи.

После ответа: пригодится снова — `taskflow_memory` · remember. Ответа нет — не держи шаг, напиши об ожидании в итоге.
