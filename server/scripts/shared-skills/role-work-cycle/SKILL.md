# Рабочий цикл роли

1. **Сверка.** Список навыков в инструкции → навык под тип работы. Скрипты роли → готовый под задачу. Память: `taskflow_memory` · recall. Карта проектов: `taskflow_knowledge` · docs.
2. **План.** `taskflow_work_plan`: пункты = критерии приёмки карточки или просьбы владельца. Неясный критерий или развилка → навык `ask-owner`, до работы.
3. **Работа.** По навыку, шаг за шагом. Однотипное больше пяти раз → навык `script-instead-of-hands`. Чтения TaskFlow пачкой — `taskflow_batch`.
4. **Проверка.** Каждый пункт чек-листа: чем подтверждён (файл, вывод команды, ссылка). Тесты без разрешения владельца не запускать.
5. **Сдача.** 1–3 предложения: что сделано, где лежит, как проверить, что не сделано. Подробности — `taskflow_knowledge` · doc_write.

Повторилась работа — оформи навык (`~/taskflow/roles/SKILL-FORMAT.md`).
