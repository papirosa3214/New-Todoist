# Скрипт вместо рук

1. Опиши вход (аргументы, файл со списком) и выход (файл, итоговая строка).
2. Положи скрипт в `~/taskflow/roles/<роль>/scripts/` или в папку навыка.
3. Требования: повторный запуск безопасен; печатает только итог и ошибки; код выхода ≠ 0 при сбое; без интерактива.
4. Прогон дольше 60 с — в фоне: `nohup bash -c "<скрипт>; echo EXIT=$?" > /tmp/<имя>.log 2>&1 &`, проверка по `tail`.
5. Пригодится снова — допиши в навык, как его звать.

Образцы: `~/taskflow/roles/analyst/scripts/measure_role_time.py`, `~/taskflow/roles/builder/scripts/merge-role-branch-to-main.sh`.
